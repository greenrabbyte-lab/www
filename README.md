# www.robalp.fr

Site vitrine de Robalp : le cas Linky (de la maison au cloud), la golden path, les critères
d'acceptation, les livraisons et les erreurs mesurées. Statique, publié par GitHub Pages à chaque
poussée sur `main` (`.github/workflows/pages.yml`). Aucune donnée personnelle.

- Domaine : `www.robalp.fr` (fichier `CNAME`) ; la zone DNS est gérée en Terraform dans
  `greenrabbyte-lab/platform` (`plateforme-azure/dns-robalp`).
- Les chiffres de la section « Mesuré » viennent de `platform/qualite/livraisons.csv` ; à rafraîchir
  avant la démo du 16 novembre.
